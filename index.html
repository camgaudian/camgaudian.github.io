Project Details

Lift: A Social Fitness App

Summer 2026

React Supabase PWA TypeScript Mobile-First
1 / 4

Lift is a personal passion project, a mobile-first social-fitness app made for tracking all kinds of exercises while staying connected to workout partners. Users log sessions from ~100 built-in or custom exercises using reusable templates, with carry-forward notes and last-session placeholders speeding up logging. Logged workouts then build up a progress section where users can enjoy fun and unique statistics about their workout journey.

A friends system enables custom exercise/template sharing, personal milestone/achievement posts and live PR leaderboards that rank lifts against friends per exercise. A Spotify-powered song sharing feature lets friends see and emoji-react to each other's workout soundtracks, surfaced through a notification center with web push alerts. Profiles also include milestone badges, customizable colors, and profile photos.

Stats dashboards visualize cumulative volume and weekly trends via Recharts. Built with React 19, TypeScript, and Tailwind CSS, backed by Supabase for authentication, Postgres storage, Row-Level Security, and Edge Functions, all packaged as an installable, offline-capable PWA.
